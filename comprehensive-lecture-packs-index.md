# CS 343 Comprehensive English Lecture Packs

These sixteen English Markdown lecture packs are designed as approximately 120-minute undergraduate sessions. Each includes learning outcomes, instructor-ready explanatory content, a code or Mermaid artifact, classroom work, comprehension checks, homework, and an 18-slide teaching sequence that can be directly converted into a PowerPoint deck.
